# Quizzical React

Quizzical is a fun React-based quiz game that fetches random trivia questions from the [Open Trivia Database API](https://opentdb.com). Users can answer multiple-choice questions and see their scores.

## Features

- Random trivia questions from OpenTDB
- Multiple-choice answers
- Immediate score and result feedback
- Option to play again

## Installation

```bash
git clone https://github.com/your-username/quizzical-react.git
cd quizzical-react
npm install
npm start
